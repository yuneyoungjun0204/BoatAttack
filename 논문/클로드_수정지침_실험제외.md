## 0. 전제 — 방법-결과 정합성 (먼저 본문에 1문장 명시)
방법 서술은 **개선본**(각도 (sin,cos) 정규화, 관측 차원 갱신 등)으로 갱신하되, 기존 정량 결과(포획률 65%, LOS 15%)는 **원본 방법으로 얻은 값**이다. 따라서 "방법 갱신 + 기존 결과 유지 + 재현은 향후 과제" 임을 §학습 결과 또는 §결론에 한 문장으로 명시한다.
> 예: "본 절의 관측·정규화 설계는 개선된 최신 구현을 반영하며, 정량 결과는 동일 프레임워크의 이전 학습본에서 얻은 것으로, 개선본 재학습을 통한 재현은 향후 과제로 둔다."

## 2. MA-POCA 설계 근거 강화 (피드백 B, 정성 부분만) ⭐⭐
> ⚠ **정량 ablation(MAPPO 비교 실험)은 하지 않는다.** 정성적 논증만 보강.
- **문제**: MA-POCA 채택 근거가 추상적이고, 타 MARL 대비 적합성이 한 문장뿐.
- **수정** — MA-POCA 소개 문단 뒤에 다음을 추가:
  1. **포획 시나리오의 3가지 이탈 상황을 구체적으로 명시**: (i) 한 선박이 적을 포획하고 임무 종료, (ii) 아군·모선과 충돌해 비활성화, (iii) 차단망 대형 붕괴로 쌍 해체 — 이들이 **한 에피소드 내에서 팀 구성원 수를 동적으로 변화**시킨다는 점.
  2. **타 알고리즘이 왜 부적합한지 구체화**: MADDPG·QMIX는 결합 가치함수를 **고정된 N개 입력**으로 정의 → 이탈 시점 이후 보상을 사라진 에이전트 기여로 역전파 불가(크레딧 누락). MAPPO는 사후 크레딧 메커니즘 부재 → 이탈 직전 행동의 장기 가치 과소평가.
  3. **MA-POCA의 부합성**: Attention 기반 가변 입력 비평가 + 사후 크레딧 할당으로 이탈한 에이전트의 기여까지 소급 평가 → 위 세 상황 모두에서 일관된 학습 신호 유지.
  - (선택) 비교 표 추가: 알고리즘 × {가변 팀 구성, 사후 크레딧, 본 문제 적합성}.
- **마무리 문장**: "정량적 ablation(MAPPO 대비)은 향후 과제로 둔다."

## 3. 수식–문제 연결 설명 보강 (피드백 C) ⭐
- **문제**: 가치·Attention·advantage·PPO·LSTM·정규화 식이 일반 알고리즘 설명에 머묾.
- **수정**: 각 식에 **"본 포획 문제에서 무슨 역할인가"** 를 1~2문장 첨언.

| 식 | 첨언할 포획-연결 설명 |
|---|---|
| 팀 가치 V(s) | 두 USV가 차단망을 함께 좁혀 **포획에 근접한 정도**를 팀 가치로 환산 |
| Attention α_ij | 포획 국면에서 **어느 파트너의 기동이 차단 성공에 결정적인지** 가중 |
| 기준선 b_j | **선박 j가 없었다면의 포획 가치** = j의 순수 차단 기여 분리 |
| Advantage A_j | j가 포획완료·충돌로 이탈한 뒤에도 **이탈 직전 차단 기동의 가치를 소급 평가** |
| PPO clip | 파도·외란으로 관측이 흔들려도 **포획 정책이 급변하지 않게** 보장 |
| LSTM 게이트 | 적의 **경로·속도·가속도 추세**를 누적 기억해 단일 시점으로 불가능한 차단 타이밍 판단 |
| 거리/각도 정규화 | 근접 협력·정밀 정렬 정보를 **민감하게** 만들어 포획 최종 기동 정확도 향상 |

## 4. 관측 정규화 근거 — 값 명시 + 각도 (sin,cos) (피드백 D, 값/문안만) ⭐
> ⚠ k 차이의 "정량적 학습 영향" 입증은 실험 → 제외.
- **거리 정규화 k 실제값 명시**: 적군 `k_e = 77`, 파트너 `k_p = 100`, 방위각 `k_β = 10`. (값은 코드/prefab과 정합 확인; 다르면 코드값 우선). 의미: 출력이 0.5가 되는 기준 거리 = 관심 반경. 적군은 원거리 위협 감지, 파트너는 근접 협력 간격 민감화.
- **각도 정규화를 (sin, cos) 쌍으로 갱신** (이미 구현 완료된 개선 반영):
  - 현재 본문/식(21)의 "사인 함수 단독" 서술을 **사인·코사인 쌍** 으로 교체.
  - 교체 문안: *"사인 함수를 단독으로 적용하면 ±180° 불연속은 해소되지만, 30°와 150°처럼 서로 다른 방향이 동일한 값을 가져 방위의 일대일 대응이 깨진다. 이를 해결하기 위해 식 (21)과 같이 사인·코사인 쌍으로 변환하여, 각도 차이를 [−1, +1] 범위의 연속적인 값으로 표현하면서도 모든 방향을 유일하게 구별되도록 하였다."*
  - 식 교체: `g(θ) = (sinθ, cosθ)`
  - **차원 정합**: 각도 관측이 1값 → 2값(sin,cos)이 되므로, 관측 공간 식(22)·Table 2/3의 차원(×2, ×3)을 이에 맞게 갱신(항목 9와 연동).

## 5. Heading reward 타당성 서술 (피드백 E) ⭐⭐
- **문제**: 정면 응시 유도가 차단망 포획에서 항상 유리한지, formation/접근 보상과 충돌하지 않는지 불명.
- **수정**: 선수 정렬 보상 문단에 다음 논지 추가:
  - 포획의 **본질은 "적을 바라보기"가 아니라 "적 경로를 가로막는 배치"** 임을 인정.
  - heading reward는 **정렬 보조(차단 직전 정밀 조준)** 역할이며, 대형 유지·적 접근 보상이 배치를 책임지는 주(主) 신호임을 명시.
  - 가중치(α_h)가 상대적으로 작아 **다른 보상과 충돌하지 않도록 우선순위가 설계**됐음을 서술(α 값은 항목 8 표와 정합).

## 10. Gerstner 식 명칭 교정 (피드백 I) ⭐
- **문제**: `ω=2π/λ`를 "각진동수"라 했으나 실제로는 **파수(wave number, k)**. `c=√(g·ω)` 등 위상속도/각진동수 명칭 혼동.
- **수정**: 분산관계 기준으로 명칭 바로잡기 — 파수 `k=2π/λ`, 각진동수 `ω=√(g·k)`(심해 분산관계), 위상속도 `c=ω/k`. 식과 본문 설명의 기호·명칭을 물리적으로 정확하게 정정.
