## 1. 서론 / 문제 정의
- **수요**: 어선 단속·밀수 차단·해양보호구역 침범·자폭 USV 위협 등 **비협조 선박 저지**.
- **하드킬**(미사일/함포): 확실하나 고비용·살상. **소프트킬**(GPS 재밍/스푸핑, 전자전): 비살상이나 INS/광학항법 선박엔 효과 제한 + 아군 통신 교란.
- **제안**: 두 USV가 **차단망을 전개해 침입선 추진기관을 물리적으로 구속** → 전자계 비의존, 아군통신 무영향, 저비용·비살상. 유인 위험 → **무인** 필요.
- **규칙기반 한계**: 파도·바람 외란, 불규칙 접근에 유연 대응 어려움 → **DRL/MARL** 채택.
- **기여 3가지**:
  1. 파도·바람 포함 Unity 해상 시뮬 + 협력 포획 학습 프레임워크.
  2. 에이전트 중심 극좌표 관측 + 거리범위/각도불연속 해결 정규화 설계.
  3. MARL로 2척이 차단망 공유 협력 포획을 자율 학습함을 정량 실험으로 입증.

## 2. 포획 시스템
- 2척이 편대를 이뤄 **사이에 전개한 차단망**으로 적 포획.
- 차단망은 두 선박 실시간 위치로 **동적 형상**, 폭은 선박 간 거리 비례.
- **최소 활성화 거리 이상**이어야 장력 확보 → 유효 포획. 미만이면 포획 비활성(물리 제약 반영).

## 3. 시뮬레이션 환경 (Unity)
- 구성: **모선(방어 대상)** + **아군 USV 2대** + **모선으로 접근하는 적 USV**(자폭선, 최단경로 고속 돌진).
- **외란 = Gerstner 파랑 모델**(식1~5): 다중 파형 합성으로 수면 변위(수직+수평), 첨예도 계수 Q(식4), 각진동수 ω(식5, 파장·중력 기반). **풍력**(식6): 풍향단위벡터·풍속·배율 곱을 매 스텝 선체에 외력 적용.
- **도메인 랜덤화**: 매 에피소드 파도·풍력 랜덤 → sim-to-real 전이성·강건성 확보.

## 4. 모델 구성 (MA-POCA / CTDE)
- **선택 이유**: MADDPG·QMIX는 고정 에이전트 수 전제 → 이탈 시 불안정. **MA-POCA는 사후 크레딧 할당(Posthumous Credit Assignment)** 으로 이탈 후에도 기여 평가 + 중앙 비평가가 개별/협력 기여 분리 학습 → 포획 중 이탈/완료 상황에 자연 대응.
- **구조(Fig.4~5)**: 중앙 비평가(Coach)가 전 에이전트 관측을 **Attention/Pooling**으로 받아 팀 가치 V(s) 추정(식7). Attention 가중치(식8, Q·K/√d_k), 맥락 벡터(식9). 에이전트 수 N 변해도 N×N 행렬 자동 조정 → **Scalable**.
- **사후 크레딧(식10~11)**: 에이전트 j 제외 기준선 가치 → j의 순수 상대이득 A_j 추정. 이탈해도 나머지 포획 학습 지속.
- **정책 갱신**: PPO Clipped Surrogate(식12~13).
- **개별 정책망(Fig.6, Table1)**: 관측(파트너 상대위치·차단망 길이, 적 상대거리·방위·헤딩, 모선거리) → **FC Encoder ×2 → LSTM(시계열, 경로/속도/가속 추정) → FC → Throttle·Steering 2D 연속행동**.
  - LSTM 게이트 식14~19. 하이퍼: hidden 256, layers 2, memory 128, sequence 64.

## 5. 관측값 구성 (핵심 — 우리 "독창" 정규화)
- **에이전트 중심(ego-centric) 극좌표**(NED 기준): 절대좌표 대신 자기 위치·헤딩 기준 상대 극좌표 → 회전 불변, 일반화↑.
- 관측 대상: **적/파트너/모선** (Fig.7, Table2).
- **문제**: 파트너 거리 1~50m vs 적 거리 0~5000m(스케일 불균형, 신경망이 큰 적거리에 편향) + 각도 ±180° 불연속.
- **거리 정규화(식20)**: 유계 유리함수로 [-1,1] 압축, **근거리 변화율 큼**. 대상별 상수 k 다르게(적 관측 시 원거리도 민감 / 협력선 관측 시 근거리 민감) — Fig.8. (코드형: `d/(|d|+k)`)
- **각도 정규화(식21)**: **사인 기반 삼각함수**로 ±180° 불연속 제거, [-1,1] 연속화. k 작을수록 미세 각도 해상도↑(정밀 차단 정렬 유리) — Fig.9.
- 최종 상태 = 아군관측 O_ally + 적관측 O_enemy 결합 O (식22, Table3): {아군 상대거리(1~50m)·방위·선수각, 적 상대거리(1~5000m)·방위·선수각}.

## 6. 보상값 구성 (계층적: 연속 shaping + 이벤트 sparse)
연속 보상(각 항 비중 파라미터 λ):
1. **대형 유지(식23)**: 파트너 거리가 기준거리에 근접할수록↑, 허용오차 50m(그물 길이). 벗어나면 패널티+비활성화.
2. **적 접근(식24)**: 이전−현재 적거리(감소량)가 양수일 때만 보상.
3. **선수 정렬(식25)**: 진행방향·적방향 각 cos>0일 때 보상(정면 응시 강화).
4. **시간 벌점**: 매 스텝 **−0.0001**.

이벤트 보상(Table3): **포획 +1.0 / 모선피격(돌파) −1.0 / 에이전트간 충돌 −1.0**. 포획·피격은 에피소드 조기종료, 충돌은 비활성화.
- 총보상(식27) = Σ연속 + Σ이벤트. 보상 성형(Ng et al. 1999) 근거 — 희소 목표까지 탐색공간 점진 축소.

## 7. 학습 결과
- **병렬 학습(Fig.10)**: GPU로 다중 환경 인스턴스 동시 구동, 공유 정책에 경험 공급.
- **하이퍼(Table4)**: batch 1024, buffer 20480, lr 3e-4(linear), beta 0.005, eps 0.2, λ(GAE) 0.95, epoch 3, gamma 0.995, strength 1, 정책망 256×2층 + normalize on.
- **수렴(Fig.11~14)**: 누적보상 ~1.1M스텝 후 수렴, 엔트로피 감소(탐색→결정론), 정책·가치 손실 동반 감소 → MA-POCA 안정 수렴.
- **비교 실험(수정 LOS Guidance vs RL)**: 비교 용이성 위해 공격선 1대 가정. 수정 LOS는 모선↔적 실시간 상대좌표로 가상경로 동적 생성(식28~32: 방향벡터·법선·목표위치 좌우전개·PD steering Kp3/Kd0.5·거리비례 throttle). 각 40 에피소드.

  | 지표 | Modified LOS | **RL (제안)** |
  |------|-------------|--------------|
  | Capture rate | 6/40 (15.0%) | **26/40 (65.0%)** (≈4.3배) |
  | Penetrate rate | 25/40 (62.5%) | **11/40 (27.5%)** |
  | Formation Collapse | 9/40 (22.5%) | **3/40 (7.5%)** (≈3배 감소) |

  → RL이 모든 지표 우위. 동적 적 기동에 사전정의 경로추종(LOS)은 한계, RL은 실시간 최적행동으로 복합목표 동시 달성.

## 8. 결론 / 향후 연구
- MA-POCA 사후 크레딧이 개별/협력 기여 분리 학습 실증. 외란 환경에서도 강건. 수정 LOS 대비 포획률·대형붕괴율 대폭 개선.
- **향후**: ① 다수 적 + 복수 아군 쌍 **가변 군집 제어**로 확장, ② 침입선에 **독립 회피 정책 학습 → 아군·적 상호 경쟁 진화(self-play 류)**, ③ 실해역 운용 구현.
